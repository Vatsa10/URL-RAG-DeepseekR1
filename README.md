# URL-RAG-DeepseekR1

Chat with a webpage using this powerful tool that leverages Retrieval-Augmented Generation (RAG) and DeepseekR1 models. This project allows you to interact with web content in a conversational manner, making it easier to extract insights and information.

---

## Features

- **Webpage Interaction**: Chat with any webpage by providing its URL.
- **RAG Integration**: Utilizes Retrieval-Augmented Generation for context-aware responses.
- **Vector Database**: Enable efficient and accurate retrieval of relevant information from a knowledge base
- **Streamlit Interface**: A user-friendly interface built with Streamlit for seamless interaction.

---

## Getting Started

Follow the steps below to set up and run the project on your local machine.

### Prerequisites

- Python 3.8 or higher
- Git installed
- Groq API
- Basic knowledge of Python virtual environments

### Installation

1. **Clone the Repository**
   ```bash
   git clone https://github.com/Vatsa10/URL-RAG-DeepseekR1.git
   cd URL-RAG-DeepseekR1
   ```

2. **Set Up a Virtual Environment**
   ```bash
   python -m venv myenv
   ```

3. **Activate the Virtual Environment**
   - On Windows:
     ```bash
     myenv\Scripts\activate
     ```
   - On macOS/Linux:
     ```bash
     source myenv/bin/activate
     ```

4. **Install Dependencies**
   ```bash
   pip install -r requirements.txt
   ```

5. **Run the Application**
   Start the Streamlit app:
   ```bash
   streamlit run streamlit_app.py
   ```

   Open the provided local URL in your browser to start chatting with a webpage.

---

## Usage

1. Provide the URL of the webpage you want to chat with.
2. Ask questions or request summaries about the content of the webpage.
3. The application will generate responses based on the webpage's content using RAG and DeepseekR1.
